🇮🇳 India – Data Science Job Market Dashboard

📊 Project Overview

The India – Data Science Job Market Dashboard is an interactive data visualization project developed using Microsoft Power BI and Excel. It analyzes job-market data to explore salary trends, job roles, experience requirements, locations, educational qualifications, and work modes in India’s data science industry.

The dashboard presents complex data through interactive charts, tables, a geographic map, and summary cards to help users understand job-market trends.

🎯 Project Objectives

* Analyze salary trends across different data science job roles.
* Explore job locations across India.
* Compare minimum and maximum annual salaries.
* Examine experience requirements for different experience levels.
* Understand employment modes such as remote, hybrid, and on-site.
* Explore educational qualifications required for different roles.
* Present job-market insights through an interactive dashboard.

🛠️ Tools and Technologies

* Microsoft Power BI – Dashboard development and data visualization.
* Microsoft Excel – Dataset storage and data preparation.
* Data Analytics – Exploring job-market patterns and salary trends.

📈 Dashboard Features

1. Salary Analysis

Visualizes salary information across different job roles, including minimum and maximum annual salaries.

2. Geographic Job Distribution

Uses a map to visualize locations represented in the dataset, including cities such as Bengaluru, Chennai, Delhi, Gurugram, Hyderabad, and Mumbai.

3. Experience-Level Analysis

Presents salary and experience-related metrics for different experience levels, including entry-level, mid-level, and senior-level positions.

4. Job Role Comparison

Compares roles such as:

* Data Scientist
* Data Analyst
* Business Analyst
* Data Engineer
* Machine Learning Engineer
* BI Analyst
* Python Data Analyst

5. Work Mode Analysis

Explores work arrangements, including:

* Remote
* Hybrid
* On-site

6. Education and Location Table

Displays job-related information such as educational qualifications, locations, work modes, and company names.

💡 Key Insights

The dashboard is designed to help users explore:

* Differences in salary across job roles.
* Geographic distribution of job opportunities.
* Experience requirements in the data science industry.
* Educational qualifications associated with different positions.
* Work arrangements offered by companies.

Actual findings depend on the dataset and the filters selected in the dashboard.

🚀 How to Use the Project

1. Download the Power BI .pbix file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded report.
4. If prompted, update the data source path or refresh the dataset.
5. Explore the charts, tables, map, and available filters.

Note: The report requires Power BI Desktop to explore locally. Uploading the file to GitHub does not automatically make it interactive in a web browser.
